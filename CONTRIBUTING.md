# Contributing

Use Node.js 22+, Git 2.45+ and pnpm 10.18.3.

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm lint
pnpm typecheck
pnpm build
```

`pnpm format` applies Biome formatting and safe fixes. Integration tests build the CLI and create temporary repositories in the operating system temporary directory outside the checkout, then remove them.

`dist/` is generated by build/prepack and ignored by Git; it is included in npm packages. `npm pack --dry-run` runs prepack so the executable is built before packaging. `node_modules/`, `.review/`, temporary test/install directories and `.tgz` archives must remain outside the public source repository. This is a single-package project; the esbuild install-script allowlist is in package.json rather than a workspace file.

Keep PRs focused on Git identity exposure. Explain the behavior change, use synthetic `example.invalid` data, and add meaningful regression coverage for changed behavior. All checks should pass. Preserve local-only, read-only scanning and default output privacy. Do not commit generated builds, archives, credentials or personal data. See SECURITY.md for sensitive reports.
